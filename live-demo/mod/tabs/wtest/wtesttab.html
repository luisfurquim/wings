Testador in-web

Cada controle abaixo está embrulhado num <w-test>: a moldura espia todos os eventos que o controle dispara pelo canal @all, mostra um log ao vivo e um selo. Com uma asserção registrada o selo é automático; sem ela, o teste é visual e o selo é clicado por quem confere.

Relatório de testes

O botão abaixo reúne TODOS os testes desta página num só relatório JSON: os cards acima (inclusive os visuais, no estado em que você os deixou) e os testes que cada widget declara via Testable(). A ideia é rodar tudo, conferir os visuais a olho e, com um clique, entregar o que passou e o que falhou — sem escrever relatório à mão.

Esta demonstração foi compilada com a tag wings_test, que ativa os testes Testable(); sem ela, um build normal não embarca código de teste algum.

O que fazer com esse JSON — enviar a um servidor, gravar em arquivo, comparar no CI — é decisão sua: o WINGS só produz o relatório e dispara um evento report com ele.

<w-test-report @report="fn"> · Testable() map[string]wings.CheckFunc · wings.RunAllTestables()
